# Sales Data Analysis Dashboard using Excel

## 📊 Project Overview

This project analyzes sales data using Microsoft Excel to understand sales performance, identify trends, and generate useful business insights.

## 🎯 Objectives

- Analyze overall sales performance
- Identify top-performing products
- Analyze sales by region
- Find monthly sales trends
- Compare sales and profit

- Create an interactive Excel dashboard

## 🛠️ Tools & Skills Used

- Microsoft Excel
- Data Cleaning
- Excel Formulas
- Pivot Tables
- Pivot Charts
- Data Visualization
business Analysis


## 📈 Dashboard

The dashboard provides a visual overview of important sales KPIs, trends, and performance across different categories and regions.

## 🔍 Key Analysis

The project includes:

- Total Sales
- Total Profit
- Sales by Region
- Sales by Category
- Monthly Sales Trends
- Top Products
- Low-Performing Products
- Profitability Analysis

## 💡 Business Insights

The analysis helps identify:

- Which products generate the most sales
- Which regions perform best
- Which products or regions need improvement
- How sales change over time
- Possible reasons for changes in sales performance
